Shrimad Bhagavad Geeta Jayanti

Browse Adhyay (Chapters) and access Geeta Aarati, Hanumaan Chalisa and Deep Prajwalan files.

How to add files

  • Place your media files under assets/media/ (e.g. assets/media/adhyay-1/geeta-aarati.mp3).
  • Edit data/media.json to add entries or follow the sample entries included.
  • Supported types:
    • Audio: .mp3/.ogg (will use <audio controls>)
    • Video: .mp4 (will use <video controls>)
    • PDF: .pdf (opens in browser / downloads)
